Desktop Buddy

documentación del proyecto

Un compañero de escritorio abierto y hackeable sobre ESP32, hecho por y para nuestro HackLab. Todo lo que hay aquí es una propuesta — discútela.

Las tarjetas marcadas interactiva se abren aquí mismo. Las marcadas markdown se leen mejor en GitHub, así que apuntan allí.
